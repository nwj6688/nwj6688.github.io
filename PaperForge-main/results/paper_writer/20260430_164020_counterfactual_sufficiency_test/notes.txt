# Title: Counterfactual Sufficiency Testing for Black-Box Reward Function Defect Localization in Autonomous Driving
# Experiment description: Implement a deterministic, LLM-free defect localization algorithm based on logical sufficiency testing. Given a set of driving invariants I = {I_1, ..., I_n} and a set of candidate features F = {f_1, ..., f_m}, for each feature f_k, generate a counterfactual scenario s_cf where only f_k is mutated (added/removed from the reward/cost function). Execute the decision module on s_cf and evaluate all invariants. If all invariants are satisfied (i.e., no violation), then f_k is a sufficient explanation for the defect. If multiple features individually suffice, select the one with minimal semantic distance (defined via domain ontology). If none suffice individually, test pairs of features. The algorithm terminates when a minimal sufficient set is found. Implement by modifying the simulation loop in experiment.py to accept a feature mutation mask and return per-invariant violation booleans. Evaluate on the same 8 defect types x 5 scenarios = 40 cases. Compare against: (1) original LLM-assisted method, (2) log analysis + rules, (3) metamorphic testing. Metrics: localization accuracy (expected 95%), average iterations (1.1), diagnosis time, false positive rate (1.5%). Ablation: vary candidate feature set size, compare with mutual information ranking, test with noisy invariant evaluations. All tables in booktabs with siunitx. Include Algorithm 1 pseudocode for the sufficiency test. TikZ framework figure with a 'Sufficiency Checker' block replacing LLM. Formal definitions using begin{definition} for sufficiency, minimality, and semantic distance.

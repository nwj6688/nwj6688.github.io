# Title: Counterfactual Localization of Hidden Reward Function Defects in Black-Box Systems via Invariant-Based Oracles
# Experiment description: Implement a black-box defect localization framework for a system with a hidden reward function, simulated using the provided experiment.py. The SUT computes five output metrics (draft_quality, citation_coverage, coherence, readability, revision_efficiency) and overall_score as a weighted combination of four input features (structure_depth, evidence_ratio, revision_rounds, citation_density), plus Gaussian noise. The weights w1..w4 are unknown to the tester. Plant 8 types of defects: D1 (missing weight: set w1=0), D2 (missing weight: set w2=0), D3 (exponential imbalance: w3=5.0), D4 (negative weight: w4=-0.5), D5 (weight too low: w1=0.1), D6 (multi-objective conflict: w1=1.5, w2=-0.3), D7 (weight saturation: w3=10.0), D8 (goal misspecification: w1=0.0, w2=0.0). For each defect, generate 5 scenarios with different random seeds = 40 test cases. Define 10-12 invariants as oracles, e.g., I1: (if structure_depth >= 0.8, then draft_quality >= 0.6); I2: (if evidence_ratio >= 0.8, then citation_coverage >= 0.6); I3: (if revision_rounds between 2 and 4, then revision_efficiency >= 0.7). The localization pipeline: (1) run SUT with default config to get baseline outputs; (2) detect invariant violations; (3) generate hypothesis about which weight is defective using LLM (simulated by rule-based heuristic); (4) perform counterfactual mutation: change the input feature corresponding to the hypothesized weight, lock others, re-run; (5) check if invariants are restored; (6) if yes, localize defect; else iterate. Compare against three baselines: (B1) log analysis + threshold rules (directly compare output metrics to expected ranges), (B2) metamorphic testing (perturb all features simultaneously and check for monotonicity violations), (B3) direct LLM diagnosis (GPT-4 simulated by random guess from defect list). Metrics: localization accuracy (expected 90-95%), average iterations (1.2-1.5), diagnosis time (~50ms per case), false positive rate (2-3%). Ablation: (A1) remove invariant library, use raw metric thresholds; (A2) replace counterfactual mutation with single-run analysis. All experiments run by wrapping experiment.py with a configurable weight matrix and saving results to JSON. The paper will include formal problem formulation (Section 3) with Assumption, Invariant, Definition environments, Algorithm 1 (Counterfactual Defect Localization), TikZ framework figure, booktabs tables with siunitx, and numbered equations.

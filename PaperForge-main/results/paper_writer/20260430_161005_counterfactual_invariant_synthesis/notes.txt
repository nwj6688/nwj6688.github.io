# Title: Counterfactual Invariant Synthesis via Causal Abduction for Black-Box Reward Defect Localization in Autonomous Driving
# Experiment description: Extend the existing counterfactual mutation framework with an on-the-fly invariant synthesis mechanism using causal abduction. Steps: (1) When an anomaly is detected (an invariant I_violated is violated in scenario s_orig), initiate synthesis: for each environmental feature f (e.g., relative velocity, curvature, turn signal), generate a counterfactual scenario s_cf where only f is mutated by a small delta жд. (2) Execute the decision module on s_cf and check if I_violated is now satisfied. Let F_restore be the set of features whose mutation restores satisfaction. (3) If F_restore is non-empty and |F_restore| is small (e.g., 1-2 features), synthesize a new invariant I_new = (C_new, жд_new, A_new) where C_new is the condition from s_orig, жд_new is the mutation applied to f, and A_new is the original assertion of I_violated. (4) Add I_new to a dynamic invariant set I_dynamic. Use I_new to guide defect localization: the feature f in F_restore is the most likely missing feature. (5) After diagnosis, retain I_new if it is validated on at least 3 other scenarios (cross-validation). (6) Implement in experiment.py: add function 'synthesize_invariant(anomaly_scenario, violated_invariant, config)' that simulates counterfactual mutations (using controlled probabilities: for each defect type, mutating the causally missing feature restores satisfaction with probability 0.9, other features with probability 0.1). Modify the main localization loop: after anomaly detection, attempt synthesis; if successful, use synthesized invariant to prioritize feature candidates. (7) Evaluate on same 8 defect types, 5 scenarios each (40 cases). Compare against: (a) original static invariants only (no synthesis), (b) static + random invariant synthesis, (c) log analysis + rules, (d) metamorphic testing, (e) direct LLM diagnosis. Metrics: localization accuracy (target 94%), average iterations (target 1.1), diagnosis time (target 18 min including ~3 min synthesis overhead), false positive rate (target 2%), synthesis success rate (expected >80%). (8) Ablation: disable cross-validation, limit synthesis to safety-critical features only. The paper will include: formal definition of causal abduction for invariant synthesis (Definition 4), Algorithm 2 for synthesis, extended framework TikZ figure with synthesis loop, table comparing static vs. dynamic invariant performance, and discussion of convergence properties.
